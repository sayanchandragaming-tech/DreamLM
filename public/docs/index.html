Getting started

DreamLM documentation

A short guide to using the current DreamLM website.

Access the workspace

The interactive workspace is in private beta. If you are authorized, sign in from the home page with your email and password or choose Google sign-in. Access is checked for the signed-in account.

Start a conversation

Enter a question in the message field and select Send. You can also choose one of the example prompts on the welcome screen. Use the mathematical glyph control to insert symbols into your input.

Manage conversations

Open the chat list to return to a saved conversation. Conversation options include rename, export as Markdown or text, and delete. Message actions include copy and retry where available.

Change appearance

Open the account menu and select Custom Theme to choose a workspace appearance.

Privacy note

Conversations are saved in this browser and are sent to the DreamLM response service when you submit them. The application states that conversations may be reviewed by Dream Circuit for beta testing, debugging, safety, and model improvement. See the privacy page for details.
